# Contributing

Make each change on a short-lived branch and open a pull request. Describe the change, identify its source section, and report the checks you ran. The checks are advisory. A reviewer will review the pull request before it is accepted.

Use short commit messages in the imperative mood, such as `Clarify setup steps`. Run `python3 scripts/check-before-push.py` before pushing any branch because pushed content is public immediately.

Engagement repositories use `cc-<client>-<solution>`. The client part is a short business name written in lowercase letters, digits, and hyphens. Do not use a person's name. The solution part must exactly match the suffix of the template repository used. For example, `cc-example-crm-activation` uses `cc-template-crm-activation`. The reserved client values `template` and `base` are not used.

Internal product repositories are exempt from the naming convention.
